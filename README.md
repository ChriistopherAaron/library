# Library Project

A lightweight web application built as part of [The Odin Project](https://www.theodinproject.com/) JavaScript curriculum. This app allows users to maintain a personal book library by adding new books, toggling read status, and deleting entries from their list.

## Features

- **Add New Books:** Modal form overlay to submit book details (Title, Author, Page Count, Read Status).
- **Interactive Storage:** Dynamic creation and rendering of book cards on a responsive grid.
- **Status Toggle:** Prototype-linked method on each book object to dynamically toggle between "Read" and "Not read yet".
- **Remove Entries:** Functionality to remove individual books from the array and update the DOM.

## Tech Stack

- **HTML5:** Semantic elements (`<dialog>`, `<main>`, `<form>`).
- **CSS3:** Responsive CSS Grid, Flexbox, and custom styling.
- **JavaScript (ES6):** Object Constructors, Prototypal Inheritance, Array Manipulation, and DOM Manipulation.
